## Задача 1 — Backend: AI chat API route
**Статус:** ✅
**Файл:** `app/api/ai/chat/route.ts`

Создать POST endpoint `/api/ai/chat`:
- JWT-аутентификация
- Загрузка всех данных пользователя (транзакции, счета, категории)
- Формирование контекста для ИИ (сводка по доходам/расходам, топ категории, балансы)
- Запрос к Groq API (llama-3.3-70b-versatile)
- Системный промпт: финансовый советник, короткие ответы (2-4 предложения), конкретные персонализированные советы, без банальностей
- Возврат ответа ИИ
