# Функции проекта Movo

Актуальное состояние на: 2026-10-30  
Стек: Flutter (mobile) + Next.js (web/API) + MongoDB Atlas

---

## 🟢 Основные функции (реализованы)

### Аутентификация и безопасность
- Регистрация пользователя (`/app/api/auth/`, `login_screen.dart`, `register_screen.dart`)
- Вход по логину и паролю (JWT)
- PIN-код при входе — установка, подтверждение, сброс (`pin_screen.dart`)
- Биометрическая аутентификация (fingerprint/Face ID, `settings_screen.dart`)
- Выход из аккаунта с подтверждением через PIN
- Хранение PIN через `SecureStorageService` (AES-256 / Keychain)

### Счета
- Создание счёта с именем, иконкой, цветом и начальным балансом (`accounts_screen.dart`)
- Редактирование счёта
- Удаление счёта (со всеми транзакциями)
- 16 иконок для счёта (карта, кошелёк, банк, крипта, инвестиции и др.)
- 16 пресет-цветов + произвольный через ColorPicker
- Карточки счётов в виде красивых банковских карт с градиентом
- Карусель счётов на главном экране с пагинацией
- Общий баланс всех счётов в шапке

### Транзакции
- Добавление транзакции (доход / расход) через bottom sheet (`add_transaction_sheet.dart`)
- Выбор счёта, категории, суммы, описания и даты
- Лимит суммы: максимум 10 триллионов
- История транзакций с фильтрацией (`transactions_screen.dart`)
- Отображение последних 5 операций на главном экране
- Спарклайн-графики доходов и расходов за 7 дней

### Категории
- Создание кастомной категории с именем, иконкой, цветом и типом (`categories_screen.dart`)
- 16 иконок категорий (шопинг, авто, кино, еда, путешествия и др.)
- Фильтрация категорий по типу (расходы / доходы)
- Отображение суммы по категории (всего и за месяц)
- Доnut-диаграмма расходов по категориям на экране категорий
- Удаление категории

### Аналитика
- Экран аналитики с переключением периода: месяц / 3 месяца / год (`analytics_screen.dart`)
- Карточка баланса за период (доход − расход)
- Столбчатый график по 6 последним месяцам (доходы и расходы)
- Donut-диаграмма топ-5 категорий расходов с процентами и прогресс-барами
- График динамики баланса за 30 дней (CustomPainter, gradient area chart)

### Главный экран (Dashboard)
- Суммарный баланс всех счётов
- Карусель банковских карт
- Сводка месяца (доходы / расходы со спарклайнами)
- Быстрые действия: добавить доход, расход, история, сканер чека
- Динамика баланса (line chart за 30 дней)
- Последние 5 операций

### Настройки и профиль
- Отображение имени и логина пользователя
- Статистика: кол-во счётов и транзакций
- Смена языка интерфейса: RU / EN / UZ
- Смена системной валюты: UZS / USD / RUB
- Управление PIN-кодом (вкл/выкл)
- Управление биометрией (вкл/выкл)
- Конвертер валют (`CurrencyCalculatorWidget`)

### Сканер чеков
- Сканирование и распознавание чека (`receipt_scanner_sheet.dart`)
- API маршрут `/app/api/scan-receipt/`

### Голосовой ввод
- API маршрут `/app/api/voice/`

## 🟡 Второстепенные / вспомогательные функции

### API и инфраструктура
- Rate limiter для API (`lib/rate-limiter.ts`)
- Keep-alive пинг для Render.com (`lib/keepAlive.ts`)
- Подключение к MongoDB с переиспользованием соединения (`lib/db.ts`)
- JWT утилиты: sign / verify (`lib/auth.ts`)
- Zod-валидация входных данных (`lib/validators.ts`)
- Health check endpoint (`/app/api/health/`)
- Proxy маршрутизация (`proxy.ts`)
- Instrumentation Next.js (`instrumentation.ts`)

### AI-функции
- AI-endpoint (`/app/api/ai/`) — статус неизвестен
- Groq API интеграция (ключ в `.env`)

### Администрирование
- Admin endpoint (`/app/api/admin/`)

### Валюта
- Курс валют (`/app/api/currency/`)
- Конвертер UZS / USD / RUB в виджете

### Пользователь
- Обновление профиля (`/app/api/user/`)

### UX / UI детали
- Локализация: `lib/l10n/` — RU, EN, UZ
- Поддержка нотча / safe area
- Pull-to-refresh на главном экране
- Skeleton / loader состояния
- Анимированные контейнеры (AnimatedContainer, AnimatedSize)
- Custom painters: спарклайн, столбчатый граф, donut, line chart
- Кастомный форматтер для поля суммы (только цифры и точка)
- Адаптивные иконки счётов (16 вариантов)
