## 🏗️ Архитектурные решения

<!-- Принятые решения, которые не нужно пересматривать -->

- Проект — монорепо: Flutter (мобильное приложение) + Next.js (API + веб)
- API — Next.js App Router, routes в `app/api/`
- БД — MongoDB Atlas через Mongoose
- Flutter использует Provider для стейт-менеджмента
- Аутентификация — JWT (lib/auth.ts)
- Валидация — Zod (lib/validators.ts)
